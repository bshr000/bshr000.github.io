## 多模态目标检测

YOLO-CMFM 面向可见光与 SAR 遥感影像的多模态目标检测，结合边缘引导与门控交叉注意力融合，探索两种成像模态的互补信息。

论文：*YOLO-CMFM: A Visible-SAR Multimodal Object Detection Method Based on Edge-Guided and Gated Cross-Attention Fusion*，发表于 Remote Sensing，2026，18(1): 136。

## 智能检测平台

围绕可见光–SAR 目标检测开展平台开发，将模型研究与应用展示相结合。模型代码与平台代码分别维护，可通过本页的 Model Code 和 Platform Code 访问。
