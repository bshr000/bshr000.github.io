## 项目简介

大模型评测方向的平台开发实践。
主要工作：
构建遥感领域评测数据集，整理 1000+ 条评测样本，覆盖 LLM、VLM两类模型。
设计自动评分流程，实现答案匹配、关键词覆盖、JSON格式校验与字段抽取准确性等指标的自动计算。
基于 Streamlit 搭建轻量级多模型评测平台，支持 Deepseek、Qwen、GPT、Gemini 等模型统一接入与批量评测。
设计多 Prompt 对比评测模式，用于辅助模型选型与提示词Prompt优化。
开发结果分析模块，支持模型对比、场景分项评分、失败案例分析和评测结果导出。
主要技术栈：Python、Streamlit、Pandas、OpenAI API 、Google AI studio
