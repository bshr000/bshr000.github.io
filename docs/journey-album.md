# 章节式相册模板

小学相册 `galleries/2007-stage-01.json` 是第一个实例。其他相册保持原有展示；在相册 JSON 顶层加入 `"presentation": "chapters"` 即可启用章节模板。

## 内容结构

- `label`：阶段名称，例如“小学”。
- `introduction`：封面上的简短介绍。
- `coverImages`：从本相册中选出的 3 张封面图片路径。
- `sections`：按阅读顺序排列的章节，每章包含 `title`、`description` 和 `images`。
- 照片字段：`src`、`alt`、`caption`、真实 `width` / `height`；可选 `featured: true` 用于重点展示。

章节阅读、照片索引、筛选与大图查看共享同一份 sections 数据。不需要再维护一份重复的 images 清单。每张照片仅归入一个章节；序号与照片数量自动生成。

## 维护规则

1. 新照片先放入 public/images/journey/ 对应目录，再填写路径与真实尺寸。
2. 说明只描述已知信息；日期与人物关系不确定时留空，不编造。
3. 低分辨率照片保留原图，模板会限制默认展示尺寸。放大查看不会增加图片本身的细节。
4. 封面照片必须来自章节列表，推荐一张横向主图、一张竖图、一张横向小图。
5. 阶段 MDX 的 previewImages 是时间线预览，stories 中的 StoryImage 是故事配图；换图时同步检查两处。
6. 小学阶段现在使用 53 张现存照片。原清单中的“小学12.webp”未找到，暂不引用；补回文件后可加入适当章节。
7. 修改后运行 pnpm lint 和 pnpm build，再在本地检查照片、筛选、大图与手机布局。
