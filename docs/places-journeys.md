# 地点与行程维护

地点位于 `lib/life/travel-map/data/places.ts`，行程位于 `lib/life/travel-map/data/journeys.ts`。

每条行程需要唯一 id、title、placeIds，以及：

```ts
status: 'visited', // 已走过；想去为 'wishlist'
color: '#B87345', // 浅色模式
 darkColor: '#E8A578', // 深色模式
```

现有四条行程均为 visited。首次进入行程模式默认显示已走过的路线。想去的行程可在“全部”或“想去”筛选下单独显示；没有想去行程时显示空状态，不添加虚构示例。

路线显隐、站点展开独立控制；显示全部/隐藏全部只影响当前筛选结果。切换筛选不会删除其他路线的选择。定位路线会自动显示该路线，并保留其他可见路线。查看全图恢复所有当前可见路线的视野。

placeIds 按停靠顺序填写，允许重复，例如两次昆明。地图标记去重，路线和站点列表保留重复停靠。

颜色区分行程；已走过使用实线，想去使用虚线。连线仅表示地点间顺序，不是实际道路或步行轨迹。

日期未知可不填 startDate/endDate，不使用占位日期。公开地图位置为近似 WGS84 城市或景区代表点。

## 跟随 BadMo 播放

每张行程卡片的“跟随 BadMo”按钮启动单条行程。播放顺序来自 placeIds，保留重复停靠。

- 每段移动约 4.5 秒，使用平滑起步和减速；每站停留至少 4 秒，随 description 长度延长，最多 15 秒。
- 到站文字来自 places.ts 中的 description，空字符串只显示地点名称。
- 暂停/继续保留当前位置；上一站/下一站跳转到站点，暂停状态不变；重新开始从第一站自动播放。
- 地图手动移动后停止跟随，点击“回到 BadMo”恢复。切换后台自动暂停。
- 系统减少动态效果模式采用逐站切换，不播放沿线移动与角色动画。
- 播放期间隐藏右下角宠物；退出、切换页面或播放器卸载后恢复。播放不会写入或更改行程数据。
- 移动时使用左右奔跑帧，暂停时冻结当前动作，到站恢复静止姿势，结束时播放一次挥手。镜头按路段取景，避免逐帧追赶。

实现：BadMoTour.tsx / BadMoTour.module.css；播放时序与坐标插值：lib/life/travel-map/tour.ts。
